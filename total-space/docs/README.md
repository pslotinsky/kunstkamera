# Total Space Documentation

- [Game design](./game/README.md) — game concepts, canonical gameplay rules, and authored content.
- [Technical design](./tech/README.md) — software representation of game concepts and implementation constraints.
- [UI references](./mockups/README.md) — campaign and battle presentation and interaction.

Game and technical documents are each self-contained. Cross-links point to specific information that helps the reader understand a rule or design decision.

When a mockup and a game-rule document disagree about gameplay behavior, [game/](game/) is authoritative. Mockups are authoritative only for the presentation and interaction decisions they explicitly demonstrate.
