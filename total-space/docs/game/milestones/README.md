# Development Milestones

Milestones describe the expected state of the game at major stages. They are not a task roadmap.

| Stage              | Expected state                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------- |
| **Prototype**      | The core strategic loop is implemented cheaply enough to test whether it is interesting.      |
| **First Playable** | A small but coherent Total Space campaign can be played from start to finish.                 |
| **Alpha**          | All committed major game systems exist and interact in a complete campaign.                   |
| **Beta**           | Major feature work is finished; focus is balance, bugs, usability, performance, and polish.   |
| **Release**        | The game meets the agreed shipping bar for content, stability, UX, balance, and presentation. |

Only stages with project-specific decisions need their own document. [prototype.md](prototype.md) is currently the only detailed milestone specification.
