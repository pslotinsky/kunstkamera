# Ships

Prototype ship content.

- [ship-roster.md](ship-roster.md) — canonical names, visual mapping, roles, branches, and unlock tiers.
- [prototype-ships.json](prototype-ships.json) — canonical numeric balance values.
- `images/*.webp` — individual transparent ship sprites, lossless, on a uniform 512×288 canvas at shared scale.

System rules belong in [fleets.md](../../systems/fleets.md), [recruitment.md](../../systems/recruitment.md), and [fleet-combat.md](../../systems/fleet-combat.md).
