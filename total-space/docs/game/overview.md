# Full Game Overview

This is the compact map of the intended final game. It does not define rules; canonical rules belong in the linked documents. Each system document defines the game concepts and rules it owns.

Read from campaign foundations through development and warfare, then faction management and campaign variety and goals. For prototype scope, see the [prototype milestone](milestones/prototype.md).
