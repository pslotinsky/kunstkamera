# Events, Missions & Crises

**Status:** CONCEPT

## Purpose

Create a dynamic galaxy and campaign-specific situations without replacing systemic strategy with a scripted narrative.

## Planned Scope

- conditional events;
- event chains and choices;
- exploration events/anomalies;
- faction and character events;
- economic, military, and diplomatic events;
- missions/objectives;
- regional and galactic crises;
- persistent campaign consequences.

## Direction

Events should normally arise from or modify game state rather than act as isolated random bonuses/penalties.

## Open Questions

- event frequency;
- authored versus generated content;
- crisis structure;
- mission rewards/failures;
- faction story content;
- repetition controls.
