# Damage

Each surviving troop contributes to the squad's attack. The target's defense
reduces the resulting damage proportionally.

**Damage = attacking troops × attack × 100 ÷ (100 + defense)**

| Defense | Damage received |
| ------- | --------------- |
| 0       | 100%            |
| 100     | 50%             |
| 200     | 33%             |
