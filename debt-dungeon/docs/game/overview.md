# Debt Dungeon — Game Systems Overview

**Status:** CONCEPT

This is a compact map of the intended **target game**. Rules belong in their respective system documents.

| System         | Responsibility                                                                | Document                                 |
| -------------- | ----------------------------------------------------------------------------- | ---------------------------------------- |
| Narrative      | Protagonist, premise, motivation, and story progression                       | [narrative.md](systems/narrative.md)     |
| Dungeon        | Floors, distribution of labyrinths, and travel restrictions                   | [dungeon.md](systems/dungeon.md)         |
| Labyrinths     | Domains, owners, condition, and individual identity                           | [labyrinths.md](systems/labyrinths.md)   |
| Territory      | Domain expansion, terrain types, and land transformation                      | [territory.md](systems/territory.md)     |
| Ordinary world | Debts, money, purchases, and interaction with the human world                 | [real-world.md](systems/real-world.md)   |
| Troops         | Single-type squads with commanders, armies, and positional turn-based battles | [troops.md](systems/troops.md)           |
| Damage         | Damage calculation from troop attack and target defense                      | [damage.md](system/damage.md)            |
| Workers        | Scouting, construction, resource gathering, and economic tasks                | [workers.md](systems/workers.md)         |
| Creatures      | Individuality, experience, evolution, rarity, and unique heroes               | [creatures.md](systems/creatures.md)     |
| Economy        | Crystals, energy, food, upkeep, and resource allocation                       | [economy.md](systems/economy.md)         |
| Development    | Buildings, labyrinth levels, research, and unlocks                            | [development.md](systems/development.md) |
| Diplomacy      | Relationships, alliances, wars, vassalage, and racial compatibility           | [diplomacy.md](systems/diplomacy.md)     |
| Events         | Expeditions, quests, special encounters, and emerging threats                 | [events.md](systems/events.md)           |

## Boundaries

- **Dungeon** — the entire multilayered world; **labyrinth** — an individual domain within it.
- **Creature** — an individual entity; **troops** and **workers** — creature roles and ways of employing them.
- **Economy** defines resources and costs; **development** defines construction and research opportunities.
- **Narrative** explains the protagonist's story; **ordinary world** defines what the player can do there.

Specific races and labyrinth archetypes are listed under [content](content/README.md).
