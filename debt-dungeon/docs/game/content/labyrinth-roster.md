# Labyrinth and Race Archetypes

A preliminary list from the original Debt Dungeon concept. **No entry represents a confirmed playable faction.**

| Race / theme | Possible labyrinth identity                             |
| ------------ | ------------------------------------------------------- |
| Orcs         | Warlike clans, strength, and conquest                   |
| Goblins      | Cunning, large numbers, and economic specializations    |
| Dwarves      | Craftsmanship, mining, and sturdy structures            |
| Elves        | Magic, rare specialists, and distinctive buildings      |
| Ogres        | Large, powerful creatures                               |
| Beastfolk    | Several distinct groups and species                     |
| Undead       | Unusual requirements for existence and development      |
| Spiders      | Distinctive organization and resource-gathering methods |
| Nagas        | A distinctive culture and combat roles                  |
| Centaurs     | Mobile military forces                                  |
| Harpies      | Flying creatures and scouting                           |
| Dragons      | Rare, powerful inhabitants with high resource demands   |

The descriptions in the right-hand column are **suggestions for discussion**, not established mechanics. Some archetypes may represent entire labyrinths; others may represent creatures living within mixed domains.

## Next Step for Content

For each labyrinth actually selected, define its player fantasy, distinctive features, key creatures, economic specializations, military doctrine, relationships, and limitations.
