# Debt Dungeon — Game Content

At the `CONCEPT` stage, this directory contains **preliminary ideas for populating the world**, rather than final lists of game entities.

- [Labyrinth and race archetypes](labyrinth-roster.md).

A particular labyrinth may combine several races; a creature species does not necessarily correspond to a single political domain. The individual properties of labyrinths and the differences between them still need to be developed.
