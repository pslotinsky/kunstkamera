# Debt Dungeon — References

**Status:** CONCEPT

The game's main references are **Age of Wonders, Disciples, Total War, and Thea**.

## Confirmed Areas of Influence

| Reference      | Confirmed direction                                                                                                                                                                    |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Disciples      | The basis for positional turn-based combat: a commander-led squad takes the place of an individual creature. Also an inspiration for territorial expansion and terrain transformation. |
| Age of Wonders | An inspiration for territorial expansion and terrain transformation.                                                                                                                   |
| Total War      | One of the main references; the specific systems to draw from have not yet been defined.                                                                                               |
| Thea           | One of the main references; the specific systems to draw from have not yet been defined.                                                                                               |

References provide direction, but do not imply adopting every mechanic from these games. Debt Dungeon's own rules are described in [troops](system/troops.md) and [territory](system/territory.md).
