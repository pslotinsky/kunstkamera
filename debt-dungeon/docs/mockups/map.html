About this experiment

Can a hex map produce distinct regions connected by useful chokepoints? Generate a floor, inspect its passages, then move an expedition through it.

Movement costs, territory sizes, and sight range are prototype assumptions. Territory is an ownership preview; terrain transformation is not simulated. All state resets when you generate a new map.

Hex coordinates, conversion, distance, and pathfinding follow Red Blob Games’ Hexagonal Grids. This page runs offline.
