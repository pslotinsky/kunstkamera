# Gemstorm

Gemstorm is a fantasy strategy game about rival houses rebuilding the storm wards of Aureth. Develop provinces, command armies, recruit Guardians, and unite the island.

The game is heavily influenced by Koei's **Gemfire**. The feature designs describe Gemstorm; the specification archive documents the original game as historical research, with its original names intact. The [name crosswalk](identity/name-crosswalk.md) connects those sources to the new cast and setting.
