# Город и деградация

**Status:** CONCEPT

## Визуальные концепты

| Образ              | Состояние                          |
| ------------------ | ---------------------------------- |
| Умный мегаполис    | Современная инфраструктура         |
| Вечный ремонт      | Повсеместные стройки и ограничения |
| Островки порядка   | Работающие зоны среди распада      |
| Поселение у костра | Первобытный уклад на месте города  |

Технологии, архитектура, институты и поведение жителей могут деградировать независимо.
